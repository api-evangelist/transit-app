# transit-app

Transit — real-time public transit and multimodal trip planning across 1,000+ cities, with a public OpenAPI 3.1 API (v4 stable) covering routes, stops, departures, plans, placemarks, alerts, and vehicle positions.

## APIs

- **Transit API** — Public real-time and trip-planning API. Single OpenAPI 3.1 contract under `/v4/public` plus `/map_layers/*` for shared mobility. apiKey header auth; free tier 5 req/min, 1,500 req/month after approval. Docs at https://api-doc.transitapp.com/v4.html
